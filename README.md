# React Native Intro App

## 📱 Giới thiệu dự án
Đây là ứng dụng React Native đơn giản được xây dựng trong khuôn khổ **bài tập tuần 1**.

Ứng dụng gồm **02 trang chính**:
1. **Intro Screen**
2. **Homepage**

Luồng hoạt động:
- Khi mở app, hiển thị **trang Intro** với logo thương hiệu trong **10 giây**
- Sau 10 giây, ứng dụng **tự động chuyển sang trang Homepage**
- Trang Homepage dùng để **giới thiệu bản thân**

---

## 🧩 Chức năng chi tiết

### 1️⃣ Intro Screen
- Hiển thị logo thương hiệu
- Tự động đếm thời gian **10 giây**
- Sau 10 giây chuyển sang Homepage (không cần thao tác người dùng)

### 2️⃣ Homepage
- Hiển thị thông tin cá nhân
